> It trains a gradient-boosting classifier on aircraft-month environment and rolling-exposure features using the Airbus target convention, then writes a submission whose risk values are thresholded to 0 or 1.

**Weighted score: 3.5/10**

## Verdict
The repository contains a real, compact training and submission pipeline: the Airbus positive/negative target and chronological per-aircraft rolling features are implemented, and the pinned scripts should regenerate a file when given the Kaggle data. The headline validation is not what the README says—training uses a random row split—and there is no isotonic calibration; predict.py instead converts probabilities to hard 0/1 values. The SHAP and coastal-airport conclusions are unsupported by analysis code, and the Granite helper is never called by the solution, so the reported scores and scientific claims should not be taken on trust. A direct prompt-injection note aimed at AI reviewers and a committed redacted API key are additional serious concerns.
